IGELKOTT STORE SYSTEM v3 – SUPABASE
====================================

1. Supabase
- Öppna projektet Igelkott store.
- SQL Editor -> New query.
- Öppna schema.sql från ZIP-filen.
- Klistra in hela SQL-filen och klicka Run.

2. Skapa första konto
- Öppna kund.html.
- Klicka Skapa konto.
- Skapa ditt eget konto med en riktig e-postadress.
- Om e-postbekräftelse är aktiv: bekräfta kontot via e-post.
- Gå sedan tillbaka till Supabase SQL Editor.
- Kör sista raden i schema.sql efter att du bytt DIN-EPOST-HÄR till din e-post:
  update public.profiles set role='owner' where email='DIN-EPOST-HÄR';

3. GitHub Pages
Lägg dessa filer i ditt repo:
index.html
admin.html
kund.html
admin.js
customer.js
config.js
style.css

5. Säkerhet
config.js innehåller endast Supabase URL + publishable key.
Det är avsett för webbläsaren. Lägg ALDRIG en sb_secret_... eller service-role-nyckel i GitHub.
RLS i schema.sql skyddar kunddata.
