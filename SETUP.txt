IGELKOTT STORE SYSTEM v4

1. Du har redan kört v3-SQL och skapat ditt owner-konto.
2. Kör NU schema-v4.sql i Supabase -> SQL Editor -> New query -> Run.
3. Ladda upp alla v4-filer till GitHub och ersätt de gamla filerna.
4. Öppna GitHub Pages igen.
5. Logga in som owner.
6. Under "Produkter & lager" klickar du "+ Ny produkt".
7. Fyll i produktnamn, SKU, kategori, pris, inköpspris och lagerantal.
8. Kunder kan se produkter som är markerade "Synlig för kunder".

Viktigt:
- config.js innehåller endast Supabase publishable key. Lägg ALDRIG in en Supabase secret/service-role key här.
- Produkter skyddas av RLS. Kunder kan läsa publicerade produkter men kan inte ändra lager.
- Owner/admin/staff kan lägga till och ändra produkter.


V4.1 – SERVICEÄRENDEN:
Kör schema-v4.sql igen i Supabase SQL Editor efter att du laddat upp denna version. Den lägger till prisfältet på serviceärenden.
